# 安装与使用：豆瓣阅读记录 0.1.0 测试版

## 文件与状态

- `DoubanReadingRecords.zip`：直接通过 Calibre“从文件加载插件”安装的个人记录插件。
- `NewDouban.zip`：原公共元数据插件，已经安装就可以继续使用现有版本。
- 完整源码和文档：[`plugins/douban/`](https://github.com/threeyang3/CalibrePlugins/tree/main/plugins/douban)，不能直接当作插件安装。

这是尚待真实登录验收的测试版。先新建一个 Calibre 测试书库，加入 2–3 本自己在豆瓣上已经标记过的书，不需要一开始全库读取。

## 安装和建列

1. Calibre → 首选项 → 高级 → 插件 → 从文件加载插件，选择 `DoubanReadingRecords.zip`。按 Calibre 提示确认，并将“豆瓣阅读记录”加入主工具栏。
2. 重启 Calibre。入口没有出现时，在“首选项 → 工具栏与菜单”中将它加入主工具栏。插件只在书库视图使用。
3. 打开入口，点击“创建所需的四个列”。逐个确认名称与类型，保留固定查找名。
4. 按提示再次重启，使列结构生效。这是 Calibre 新建自定义列的要求；同一次操作可连续创建四列。

| 查找名 | 显示名 | 类型 |
| --- | --- | --- |
| `#douban_my_tags` | 豆瓣个人标签 | 文本，可包含多个值／类似标签 |
| `#douban_my_rating` | 豆瓣个人评分 | 评分 |
| `#douban_read_status` | 豆瓣阅读状态 | 单值文本 |
| `#douban_my_comment` | 豆瓣简评 | 长文本／评论 |

如果已有同查找名但类型不同的列，插件会停止，需先核对。当前版本尚未提供任意自定义列映射。

## 确认书籍关联

在“编辑元数据”的标识符中，确认存在原插件产生的 `new_douban:<数字>`，或填写 `douban:<数字>`。

例如豆瓣地址是 `https://book.douban.com/subject/1084336/`，标识符就是 `douban:1084336`。这只是格式示例，并不表示该条目适合你选中的电子书。

没有 ID 时，先用原 New Douban Books 下载元数据，再核对作者、译者、出版社、ISBN 与版本。配套插件不按标题猜测。两个豆瓣标识符同时存在且不同，会被明确跳过。

## 登录

点击“登录 / 切换豆瓣账号”，在豆瓣真实网页里自行完成扫码、账号登录及验证码，然后点击“完成登录”。按钮只表示让插件继续核对，并不代表验证已经成功。

后台会核对 `/mine/` 返回的账号，成功后显示账号名字和 ID。会话只保存在本次 Calibre 进程内，退出 Calibre 后需重新登录。插件没有自己的密码表单，不把 Cookie 存进书库或导出文档。

如果内嵌网页不可用，点击“使用已登录浏览器的 Cookie…”：

1. 在本机浏览器登录豆瓣并打开豆瓣读书。
2. 打开开发者工具“网络”面板，刷新页面。
3. 选择发往 `https://book.douban.com/` 的页面请求，在请求头中复制 `Cookie` 的值。
4. 在插件的密码掩码输入框中粘贴，点击“继续核对账号”。

Cookie 相当于当前登录凭证，只在本机输入，不要发到聊天或 GitHub issue。没有必要为此修改账号密码。

## 读取和应用

回到书库选中书籍，再打开插件点击“读取选中书籍”。支持一次多选，请求串行执行，底部显示进度。点击“取消读取”会放弃本次预览，进行中的网络请求结束或超时后停止。

每本书有四行预览，展示当前值、豆瓣值与处理原因。允许填空或安全更新的行默认勾选，受保护的行不可勾选。可以取消部分行，再点击“写入勾选项”。

只有此时才会更新 Calibre 的四个个人列。完成后可以在书库或“编辑元数据 → 自定义元数据”中查看；长简评通过自定义元数据编辑器查看和编辑。

## 最小真实验收

用已收藏的两本书完成下面的检查即可，不必在本机重复全部离线测试：

1. 一本四项完整的书：预览与豆瓣一致，写入后各列正确。
2. 一本没有评分或简评的书：空值保持空，不使用公众评分或热门短评。
3. 再次读取：没有变化的字段不重复写入。
4. 手改简评或清空评分再读取：人工修改保留。
5. 退出登录后读取：要求登录；退出并重开 Calibre 后也要登录。
6. 未收藏或无豆瓣 ID 的书：明确跳过，原记录保留。

字段未识别时，记录 Calibre 版本、系统版本、该字段在豆瓣上的显示形式及插件提示。截图应遮住不相关的账号资料；不要上传完整的登录请求或网络日志。

## 已有数据与后续调整

首次导入只填空；后续只更新与上次插件写入值一致的字段。人工修改、手动清空、账号变化、版本变化都会受到保护。当前没有强制覆盖或重新认领按钮；确实要替换受保护字段时，可从预览核对后在 Calibre 手动编辑。

本版本没有整批回滚。数据库中若部分字段已写入再发生错误，界面会显示已写入数量并停止后续写入。内部来源快照只用于更新判断，不能代替书库备份。

## 卸载

“首选项 → 插件”选择 `Douban Reading Records` 并卸载。原 New Douban Books 与书库文件保留。已导入到四个自定义列的记录会留下，是否保留这些列由你决定。
