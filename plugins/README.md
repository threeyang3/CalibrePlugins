# 插件目录约定

每个 Calibre 插件项目放在独立目录 `plugins/<plugin-id>/`。目录内包含 `README.md`、源码、测试、构建脚本、必要的许可证/署名和使用文档。不同插件可依赖同一上游项目，但必须清楚标注上游版本与新增代码归属。

- **版本：**插件独立语义版本号；Release 标签使用 `<plugin-id>-vX.Y.Z`，避免多个项目互相冲突。
- **打包：**在插件自己的目录运行构建脚本；把可直接安装的 ZIP 放在 GitHub Release 附件，不提交在 `out/` 中生成的临时文件。
- **保护数据：**影响书库的功能必须说明写入范围、覆盖策略与备份/回滚能力。未经真实测试的版本标为预览版。
- **保留许可证：**第三方代码和新增代码均保留其适用的许可证与来源。
- **自动化：**只在对应插件的发布范围执行所需检查，避免每次仓库改动触发所有插件 CI。
