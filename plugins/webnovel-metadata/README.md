# WebNovel Metadata · Calibre 网文元数据

为 Calibre 图书库中的网文补充书名、作者、封面、简介、分类及来源链接。首版支持**起点中文网、七猫中文网、番茄小说**。

基于同作者 [webnovel-import](https://github.com/threeyang3/webnovel-import) 的平台解析经验，参考 [NewDouban](https://github.com/fugary/calibre-douban) 的 Calibre 元数据源形式，使用 Python 独立实现。每个平台单独维护，插件没有常驻服务，也不需要安装 Obsidian 或 Node.js。

## 安装

1. 使用本轮交付的 `WebNovelMetadata.zip`，或在本插件目录执行 `python3 build.py`，得到 `dist/WebNovelMetadata.zip`。构建只用 Python 标准库，无需安装测试依赖。不要将整个仓库的源码 ZIP 当成插件安装，也不要解压插件 ZIP。
2. 在 Calibre 中打开 **首选项 → 插件 → 从文件加载插件**，选择该 ZIP。
3. 按 Calibre 提示完成安装，重新启动 Calibre。
4. 打开 **首选项 → 元数据下载**，勾选 **WebNovel Metadata**。选择它并点击“配置选中的来源”可设置平台、候选数、超时和简介附注等。

版本：**0.1.0 预览版**，本轮未创建 GitHub Release。按照仓库约定，生成的 `dist/` 不提交，后续正式发行包通过独立 Release 提供。声明最低 Calibre **5.0 / Python 3.8**，使用 Calibre 自带的 `lxml`；本轮真实安装和运行验证环境为 **Calibre 6.29.0**。Windows、macOS、Linux 均按 Calibre 的通用 Python 插件接口实现；macOS / Windows 图形界面仍需对应机器验收。

## 怎么用

### 按书名和作者搜索

选择一本书，打开 **编辑元数据 → 下载元数据**。尽量提供正确的书名和作者，核对候选后采用。

- 起点：使用官方移动搜索页的服务端 JSON 数据。
- 七猫：使用官网搜索页面实际调用的公开接口。
- 番茄：已接入官网搜索接口，但部分网络会返回空响应或验证页；此时改用下面的作品 ID / URL。插件会在下载日志中说明原因，不能将接口受限理解为“这本书不存在”。

同名且作者不符的候选会被排除。作者为“未知”或“Unknown”时按书名匹配。每个平台默认最多核对 5 个候选，可配置为 1–10；未找到时可增加候选数或直接填写作品 ID。

### 按官网作品 ID 精确获取（推荐）

在 Calibre 的**标识符**栏中填写一项，例如：

| 平台 | 标识符示例 | 对应官方作品页 |
| --- | --- | --- |
| 起点中文网 | `qidian:1010868264` | `https://www.qidian.com/book/1010868264/` |
| 七猫中文网 | `qimao:195958` | `https://www.qimao.com/shuku/195958/` |
| 番茄小说 | `fanqie:7143038691944959011` | `https://fanqienovel.com/page/7143038691944959011` |

之后点击“下载元数据”。平台 ID 会保留为字符串，19 位番茄 ID 不会被浮点舍入。标识符在图书详情中可跳转回官网。

插件也接受在书名查询框中填写完整的上述详情页 URL，或使用 `url` 标识符；下载结果会返回真实书名和相应平台 ID。起点旧链接 `https://book.qidian.com/info/ID/` 同样可识别。章节链接、搜索页、分享短链不作为作品身份，请在正常浏览器中打开后复制正式详情页链接。

**明确给出平台 ID 后，只查询该作品。** ID 无效、页面身份不同或查询失败时，不会悄悄改成另一本同名书。若想重新按书名找候选，请先清除错误的平台 ID。

### 手动增加、修改元数据

继续使用 Calibre 自带的“编辑元数据”。不在插件里建立第二套编辑窗口或数据表。

本插件只提供元数据候选，实际采用哪些字段由 Calibre 的下载设置和确认流程决定。若你已把个人文字写在 Calibre 的“简介 / Comments”字段，可以在本数据源的下载字段设置中取消“简介”，保留原有文字；也可逐本预览后采用。不要把作品简介字段当成一个另外受到保护的私人笔记字段。

## 获取哪些信息

| 平台信息 | Calibre 中的位置 | 规则 |
| --- | --- | --- |
| 作品名、作者 | 书名、作者 | 必须能够可靠解析，否则不返回候选 |
| 作品简介 | 简介 / Comments | 保留段落，以转义文本生成 HTML；不执行来源脚本 |
| 封面 | 下载封面 | 使用本作品封面，排除已知加载图、作者头像及推荐图 |
| 分类 / 题材 | 标签 | 可关闭 |
| 平台作品 ID | 标识符 | `qidian` / `qimao` / `fanqie`，附官网跳转 |
| 语言 | 语言 | 中文 `zho` |
| 明确的作品首发日期 | 出版日期 | 只采用作品级 `datePublished` 或明确首发字段；缺证据留空 |
| 字数、连载状态、最新章节、更新时间 | 简介末尾来源附注 | 可关闭；连载状态也可选为标签 |

**最近更新时间不会被当作出版日期，平台名称不会被当作出版社。** 插件不采集个人评分、个人阅读进度、个人简评，也不把站点评分写入 Calibre 的个人评分字段。连载状态（连载中 / 已完结）与个人阅读状态不同。

只请求搜索、作品详情和封面，不提供正文下载、付费内容获取、账号登录或验证码处理。

## 平台可用性

最近验证：**2026-11-11**。这是本轮环境的实测结果，不保证平台以后不改变页面或访问策略。完整证据和验证范围见 [验证记录](docs/VALIDATION.md)。

| 平台 | 书名搜索 | 作品 ID / URL 详情 | 封面 |
| --- | --- | --- | --- |
| 起点 | 移动官网 SSR 搜索实测通过 | 移动官网详情实测通过；桌面页在本环境返回验证响应，可回退移动页 | 官方 600px 封面 |
| 七猫 | 官网公开搜索接口实测通过 | 已验证多本作品 | 官方封面 |
| 番茄 | 已实现官网接口；本环境返回 HTTP 200 空响应，**尚未验证搜索成功** | 已验证多本作品 | 使用绑定本书 ID 的签名图片 URL，保留签名参数 |

### 页面暂时受限：使用浏览器保存的 HTML

如果你能在正常浏览器中打开详情页，但插件不能取得：

1. 在浏览器中打开正式作品详情页，正常完成需要的访问步骤，然后保存网页为 HTML（“仅 HTML”或“完整网页”的 HTML 主文件均可）。
2. 按下列文件名放入一个本地目录：`qidian-1010868264.html`、`qimao-195958.html`、`fanqie-7143038691944959011.html`。
3. 在插件配置的“浏览器已保存详情页目录”中填写该目录的绝对路径。
4. 在 Calibre 中填写对应平台标识符，再下载元数据。

同名本地文件优先于在线抓取；需要刷新时，请替换它或移走旧文件。HTML 必须含实际作品信息与可核对的作品身份；只保存了验证页、空壳页面或其他书籍会被拒绝。此功能读取本地 HTML 中的元数据，不执行脚本；封面仍从官网图片地址下载，因此不等于完全离线下载封面。

## 配置

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| 启用起点 / 七猫 / 番茄 | 均启用 | 可只用自己需要的来源；关闭后精确 ID 查询也不请求该平台 |
| 每平台候选数 | 5 | 1–10；控制详情请求数量 |
| 单次请求超时 | 10 秒 | 1–30 秒，所有来源同时受 Calibre 总查询时间限制 |
| 最多封面数 | 3 | 1–5；Calibre 只要最佳封面时返回一张 |
| 获取分类标签 | 开 | 采用本作品标签 |
| 连载状态标签 | 关 | 可按 `连载状态:已完结` 等筛选 |
| 简介附带来源信息 | 开 | 来源、字数、连载状态、最新章节、更新时间 |
| 已保存 HTML 目录 | 空 | 可选，本地页面优先 |

查询时最多三个临时平台工作线程，完成后释放。在请求、重定向及读取之间检查总时间预算和取消信号；取消或到达总预算时，当前阻塞读取仍可能等待至单次请求超时。响应大小与重定向范围受限；一个来源失败不会阻断其他来源已经取得的结果。插件不保存账号 Cookie。

## 源码与验证

```text
plugins/webnovel-metadata/
  src/                 Calibre 插件入口、调度、网络和独立平台解析器
  tests/               离线回归、结构样本和真实 Calibre 冒烟脚本
  docs/VALIDATION.md    验证范围与已知平台限制
  build.py             可重复构建脚本
  dist/                可直接安装的 ZIP 与 SHA-256
```

在本目录执行：

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -p 'test_*.py' -v
python build.py
```

ZIP 根部直接是插件 `__init__.py` 与命名空间标记，包含运行时源码、许可证和来源说明，不含测试、缓存或完整网站页面。构建检查 Python 3.8 语法，并使用固定归档时间生成可重复产物。

真实 Calibre 冒烟验证使用独立配置目录，避免改动日常 Calibre 配置：

```bash
export CALIBRE_CONFIG_DIRECTORY="$(mktemp -d)"
calibre-customize -a dist/WebNovelMetadata.zip
calibre-debug -e tests/calibre_smoke.py
```

需要主动复核官网可用性时，可在同一隔离配置中执行 `calibre-debug -e tests/live_smoke.py -- --run-live`。它只核对起点、七猫各一项书名搜索，以及一部番茄作品 ID，并下载对应封面；该测试会联系官网，不属于离线测试。

CI 不自动运行。本轮通过本地回归与真实 Calibre CLI 验证，不消耗 GitHub Actions 额度。

## 维护边界

新增平台时增加对应解析模块并注册到 `providers`，用真实公开页面核对后补最小结构样本和必要回归。对外报告应区分“离线结构解析通过”“实际在线请求通过”“真实客户端验证通过”。本轮尚未实现晋江等其他平台，也没有自动修改 EPUB 内部元数据或封面；如需写入文件，请使用 Calibre 自带功能。
