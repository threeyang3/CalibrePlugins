## 新增网文栏目

- 新增 **连载平台、首发日期、字数、连载状态、最近更新、最新章节** 六个 Calibre 自定义列。在图书详情中点击平台名称，即可打开对应的官方作品页。
- 使用工具栏的「网文元数据」更新选中的一本或多本书。此操作保留已有封面、电子书文件「来源」、原版出版日期及个人阅读数据。
- 刷新 v0.1.0 已下载的条目时，插件会识别上一版为同一作品生成的简介附注。连载数据写入对应栏目后，简介正文和手写内容继续保留。

## 安装与使用

| 附件 | 用途 | 最低 Calibre 版本 |
| --- | --- | --- |
| `WebNovelMetadata.zip` | 从起点、七猫、番茄下载普通元数据和封面 | 5.0 |
| `WebNovelLibrary.zip` | 建立和更新网文栏目，与上面的元数据源配合使用 | 8.0 |

在 Calibre 中通过 **首选项 → 插件 → 从文件加载插件** 分别安装两个 ZIP，然后重启。在目标书库选择 **网文元数据 → 建立网文栏目**，按提示重启。选中书籍后点击工具栏的 **网文元数据** 即可更新。如果工具栏没有显示该按钮，可在 **首选项 → 工具栏与菜单 → 主工具栏** 添加。

两个安装包均附有 SHA-256 校验文件。[完整使用说明](https://github.com/threeyang3/CalibrePlugins/blob/webnovel-metadata-v0.2.0/plugins/webnovel-metadata/README.md)

## 验证范围

在 macOS 的 Calibre 9.16 通过 58 项离线测试、元数据源及书库集成冒烟测试，并在图形界面从起点更新《诡秘之主》和《武动乾坤》，核对逐书链接、简介迁移和封面保留。番茄匿名书名搜索遇到空响应时，可以用作品 ID 或官网详情页 URL 查询。
